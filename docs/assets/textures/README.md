# Tiger-stripe background

Asset: `tiger-stripes.webp`. Created with the built-in image-generation tool, then losslessly encoded as WebP with its alpha preserved. CSS uses the image as a mask so the existing theme supplies the tint. No runtime image API is used.

## Final generation prompt

Use case: stylized-concept. Asset type: a production website background texture, used as a CSS alpha mask. Create one square field of natural tiger stripes: irregular, flowing, branching, tapered black stripe silhouettes on a genuinely transparent background. Large-scale organic shapes, mostly diagonal-to-vertical tiger flank markings, unequal widths and spacing, pointed ends, broad clear spaces. About 25 percent black coverage and 75 percent transparent space. Flat, clean, crisp artwork with smooth natural contours. Make the striping unmistakably tiger-like, not regular zebra waves. The final site will tint this purple and display it very faintly behind glass panels; generate the stripes in solid black at full opacity so the alpha shape can be reused. No animal face or body, no fur texture, no white or colored background, no gradient, no glow, no text, no logo, no border, no UI. This is a standalone texture asset, not a mockup.
