# Bundled fonts

All three families are open-source under the SIL Open Font License 1.1 and are bundled locally so the site runs offline.

| Family | Role | Files | Source |
| --- | --- | --- | --- |
| Newsreader (variable, optical size + weight) | Display and editorial headings | `newsreader-latin-opsz-normal.woff2`, `newsreader-latin-opsz-italic.woff2` | https://github.com/productiontype/Newsreader via fontsource `@fontsource-variable/newsreader@5.3.0` |
| Public Sans (variable weight) | Interface and body text | `public-sans-latin-wght-normal.woff2` | https://github.com/uswds/public-sans via fontsource `@fontsource-variable/public-sans@5.3.0` |
| IBM Plex Mono (400, 500) | Evidence-record metadata, dates, locators | `ibm-plex-mono-latin-400-normal.woff2`, `ibm-plex-mono-latin-500-normal.woff2` | https://github.com/IBM/plex via fontsource `@fontsource/ibm-plex-mono@5.2.5` |

Licenses: `OFL-newsreader.txt`, `OFL-public-sans.txt`, `OFL-ibm-plex-mono.txt`. Latin subsets only.
