# SLP Assessment Website

A source-linked assessment finder and comparison demo for speech-language pathology students and clinicians.

## Live demo

https://ethanheinrick01-ctrl.github.io/SLP-Assessment-Website/

## Features

- Browse six assessments or filter by clinical area, age, purpose, and administration time.
- Compare two assessments with separate reliability measures and diagnostic-accuracy context.
- Review client-fit summaries, administration details, and direct source links.
- Compact, responsive dark interface.

## Run locally

```sh
python3 -m http.server 8765 --directory docs
```

Open http://localhost:8765. No dependencies, API keys, or paid API calls are required. GitHub Pages serves the static files in `docs` from the `main` branch.

## Evidence

This is an educational proof of concept, not an LSU-endorsed resource. Figures retain source and interpretation notes; missing estimates are not invented. Consult the cited sources and current examiner manuals when selecting or administering assessments. Referenced publisher materials remain the property of their respective owners.
